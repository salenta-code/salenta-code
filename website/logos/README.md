# Anbieter-Logos

Lege hier die offiziellen Logo-Dateien der Anbieter ab (aus deren Presse-/Brand-Kits), als SVG mit genau diesen Namen:

`claude.svg` · `codex.svg` · `cursor.svg` · `gemini.svg` · `junie.svg` · `ollama.svg` · `github.svg` · `mcp.svg` · `obsidian.svg`

Die Webseite zeigt eine Datei automatisch an, sobald sie da ist. Fehlt sie, erscheint ein neutrales Kürzel.
Am besten helle bzw. einfarbig weiße Varianten nehmen (die Seite ist dunkel) und die Markenrichtlinien der Anbieter beachten.
