[[Every coding task follows the same seven phases. In each one the agent gets exactly the extensions and skills you've installed that help there – and runs the same checks as your GitHub workflows.||Jeder Code-Auftrag folgt denselben sieben Phasen.   2. [[Implement||Umsetzen]][[Current docs instead of guesses, your project's style.||Aktuelle Doku statt Vermutungen, Stil deines Projekts.]]
    context7frontend-design
  3. [[Clean up||Aufräumen]][[No debug output, no dead code, no duplicates.||Keine Debug-Ausgaben, kein toter Code, keine Doppelungen.]]
    code-simplifier
  4. [[Check like the CI||Prüfen wie die CI]][[Lint, types, tests and build taken from your workflows.||Lint, Typen, Tests und Build aus deinen Workflows.]]
    playwright.github/workflows

    security-review

    code-review

FAQ

[[Questions||Fragen]]

[[Is it really free?||Ist es wirklich kostenlos?]]

[[Yes. Salenta Code is open source under the Apache 2.0 license. You only pay for the agent subscriptions you already use; local models cost nothing.||Ja. Salenta Code ist Open Source unter der Apache-2.0-Lizenz. Du zahlst nur die Agent-Abos, die du ohnehin nutzt; lokale Modelle kosten nichts.]]

[[Which Macs are supported?||Welche Macs werden unterstützt?]]

[[Any Mac with macOS 14 Sonoma or newer. The download is one universal app that runs natively on Apple Silicon (M1 and later) and on Intel.||Jeder Mac mit macOS 14 Sonoma oder neuer. Der Download ist eine Universal-App und läuft nativ auf Apple Silicon (ab M1) und auf Intel.]]

[[How do I install it?||Wie installiere ich es?]]

[[Open Salenta-Code.dmg and drag the app into Applications. On first launch, setup checks for Git, the GitHub CLI, Node and your agents and installs what's missing if you want.||Öffne Salenta-Code.dmg und zieh die App in den Programme-Ordner. Beim ersten Start prüft die Einrichtung Git, GitHub CLI, Node und deine Agents und installiert auf Wunsch, was fehlt.]]

[[Which agents do I need?||Welche Agents brauche ich?]]

[[At least one: Claude Code, Codex, Cursor, Gemini CLI, Junie or a local model through Ollama. The more you have, the more options routing has.||Mindestens einen: Claude Code, Codex, Cursor, Gemini CLI, Junie oder ein lokales Modell über Ollama. Je mehr du hast, desto mehr Möglichkeiten hat die Verteilung.]]

[[Does my code go to Salenta?||Geht mein Code an Salenta?]]

[[No. Salenta Code runs on your Mac and has no server of its own. Your code goes only to the agents you choose – or nowhere, in offline mode.||Nein. Salenta Code läuft auf deinem Mac und hat keinen eigenen Server. Dein Code geht nur an die Agents, die du wählst – im Offline-Modus nirgendwohin.]]

[[How do updates work?||Wie funktionieren Updates?]]

[[The app checks GitHub releases itself and installs a new version only when no agent is running and the new build passes its self-test. The previous version is kept.||Die App prüft die GitHub-Releases selbst und installiert eine neue Version nur, wenn kein Agent läuft und der neue Build seinen Selbsttest besteht. Die vorige Version bleibt erhalten.]]

[[Windows or Linux?||Windows oder Linux?]]

[[Not right now. Salenta Code is a native Mac app built with SwiftUI.||Im Moment nicht. Salenta Code ist eine native Mac-App mit SwiftUI.]]

[[Which languages?||Welche Sprachen?]]

[[English and German. The app follows your Mac's language, or you set it under Settings › General › Language.||Englisch und Deutsch. Die App folgt der Sprache deines Macs, oder du stellst sie unter Einstellungen › Allgemein › Sprache ein.]]
