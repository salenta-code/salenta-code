[[Not just a launcher. A colleague who thinks along.||Kein Startknopf. Ein Kollege, der mitdenkt.]]

[[Salenta Intelligence is the layer between you and your agents. It runs on your Mac with no server in between – picks the agent, checks the result, watches running work, learns from every task and tells you when something needs you.||Salenta Intelligence ist die Schicht zwischen dir und deinen Agents. Sie läuft auf deinem Mac, ohne Server dazwischen – wählt den Agent, prüft das Ergebnis, beobachtet laufende Arbeit, lernt aus jedem Auftrag und sagt dir, wenn etwas dich braucht.]]

  • [[Done means done. Every task gets a checkable “done when …”. The reviewer – always a different provider – checks exactly that against the diff.||Fertig heißt fertig. Jeder Auftrag bekommt ein prüfbares „Fertig, wenn …“. Der Prüfer – immer ein anderer Anbieter – kontrolliert genau das am Diff.]]
  • [[Supervisor. Notices when an agent stalls or loops on the same error, and hands the task – with its history – to another agent.||Supervisor. Merkt, wenn ein Agent hängt oder sich im Kreis dreht, und übergibt den Auftrag samt Verlauf an einen anderen Agent.]]
  • [[Learns what works. Hit rate per agent and task type – the agent choice uses it. Red twice? A fresh provider takes over.||Lernt, was funktioniert. Trefferquote pro Agent und Aufgabenart – die Agentenwahl nutzt sie. Zweimal rot? Ein anderer Anbieter übernimmt.]]
  • [[Trust that grows. Per project: after 5 green rounds, small, uncritical changes are applied on their own. Login, payments, migrations and deploys always wait for you.||Vertrauen, das wächst. Pro Projekt: Nach 5 grünen Runden werden kleine, unkritische Änderungen selbst übernommen. Login, Zahlung, Migrationen und Deploys warten immer auf dich.]]
  • [[Learns overnight. A local model turns the day's failures and fixes into suggestions for the project knowledge. You confirm them in the morning.||Lernt über Nacht. Ein lokales Modell macht aus Fehlern und Lösungen des Tages Vorschläge fürs Projektwissen. Du bestätigst sie morgens.]]
  • [[Speaks up when it matters. Freigaben, grüne oder rote Ergebnisse, fertige Pull Requests, rote CI, anstehende Termine, fällige Aufgaben und Mails, die eine Antwort brauchen – mit Ruhezeit, Morgen-Briefing und Aktionen direkt in der Mitteilung.]]

FAQ

[[Questions||Fragen]]

[[Is it really free?||Ist es wirklich kostenlos?]]

[[Yes. Salenta Code is open source under the Apache 2.0 license. You only pay for the agent subscriptions you already use; local models cost nothing.||Ja. Salenta Code ist Open Source unter der Apache-2.0-Lizenz. Du zahlst nur die Agent-Abos, die du ohnehin nutzt; lokale Modelle kosten nichts.]]

[[Which Macs are supported?||Welche Macs werden unterstützt?]]

[[Any Mac with macOS 14 Sonoma or newer. The download is one universal app that runs natively on Apple Silicon (M1 and later) and on Intel.||Jeder Mac mit macOS 14 Sonoma oder neuer. Der Download ist eine Universal-App und läuft nativ auf Apple Silicon (ab M1) und auf Intel.]]

[[How do I install it?||Wie installiere ich es?]]

[[Open Salenta-Code.dmg and drag the app into Applications. On first launch, setup checks for Git, the GitHub CLI, Node and your agents and installs what's missing if you want.||Öffne Salenta-Code.dmg und zieh die App in den Programme-Ordner. Beim ersten Start prüft die Einrichtung Git, GitHub CLI, Node und deine Agents und installiert auf Wunsch, was fehlt.]]

[[Which agents do I need?||Welche Agents brauche ich?]]

[[At least one: Claude Code, Codex, Cursor, Gemini CLI, Junie, a local model through Ollama – or the built-in Salenta Harness with an API key of your choice. The more you have, the more options routing has.||Mindestens einen: Claude Code, Codex, Cursor, Gemini CLI, Junie, ein lokales Modell über Ollama – oder den eingebauten Salenta Harness mit einem API-Schlüssel deiner Wahl. Je mehr du hast, desto mehr Möglichkeiten hat die Verteilung.]]

[[Does my code go to Salenta?||Geht mein Code an Salenta?]]

[[No. Salenta Code runs on your Mac and has no server of its own. Your code goes only to the agents you choose – or nowhere, in offline mode.||Nein. Salenta Code läuft auf deinem Mac und hat keinen eigenen Server. Dein Code geht nur an die Agents, die du wählst – im Offline-Modus nirgendwohin.]]

[[How do updates work?||Wie funktionieren Updates?]]

[[The app checks GitHub releases itself and installs a new version only when no agent is running and the new build passes its self-test. The previous version is kept.||Die App prüft die GitHub-Releases selbst und installiert eine neue Version nur, wenn kein Agent läuft und der neue Build seinen Selbsttest besteht. Die vorige Version bleibt erhalten.]]

[[Windows or Linux?||Windows oder Linux?]]

[[Not right now. Salenta Code is a native Mac app built with SwiftUI.||Im Moment nicht. Salenta Code ist eine native Mac-App mit SwiftUI.]]

[[Which languages?||Welche Sprachen?]]

[[English and German. The app follows your Mac's language, or you set it under Settings › General › Language.||Englisch und Deutsch. Die App folgt der Sprache deines Macs, oder du stellst sie unter Einstellungen › Allgemein › Sprache ein.]]
