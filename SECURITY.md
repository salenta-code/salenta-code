# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through
[GitHub's private vulnerability reporting](https://github.com/salenta-code/salenta-code/security/advisories/new)
or by email to **hello@salenta.ai** with the subject `Security`.

Please include what you found, how to reproduce it and which version you used (Salenta Code › About).
You will get an answer within a few days. Once a fix is released, we are happy to credit you in the release notes
if you want.

## Supported versions

Only the latest release receives security fixes. The app updates itself, so please stay on the newest version.

## Scope

Salenta Code starts third-party agent CLIs (Claude Code, Codex, Cursor …) and MCP servers on your Mac.
Problems inside those tools should be reported to their makers. Problems in how Salenta Code starts, approves,
sandboxes or passes data to them are in scope.
