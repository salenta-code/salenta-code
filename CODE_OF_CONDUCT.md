# Code of conduct

Salenta Code is built by people with different backgrounds and levels of experience. Please help keep it a place
where everyone feels welcome.

- Be kind and patient. Assume good intent and explain instead of judging.
- Criticize code and ideas, never people.
- No harassment, insults, discrimination or sexualized content – in issues, pull requests, discussions or anywhere
  else connected to the project.
- Respect other people's time: search before you ask, and keep issues on topic.

Maintainers may edit or remove comments and block people who break these rules.
To report a problem privately, write to **hello@salenta.ai**.
